# AI Class - Landing Page

The official public-facing website and marketing introduction for **AI Class**.

## Features
- Modern, high-performance responsive design.
- Overview of AI facial and voice attendance capabilities.
- Teacher and student journey walkthroughs.
- Environment-aware CTAs that link directly to the deployed AI Class application.

## Local Setup

```bash
pip install -r requirements.txt
copy .env.example .env
python app.py
```
The landing page will start on `http://localhost:5000` and link to `MAIN_APP_URL` (default: `http://localhost:5002`).

## Deployment
Can be deployed to Vercel via `vercel.json` or Render as a Python Web Service.
